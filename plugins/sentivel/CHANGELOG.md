# Changelog

## 1.0.0

- Added the `sentivel` MCP server, which points at Sentivel's hosted Streamable HTTP endpoint (`https://mcp.sentivel.com/mcp`). It signs in with OAuth and needs no API key.
- Added the `set-up-monitoring` and `run-an-incident` skills.
- Added the `/sentivel-setup` and `/sentivel-status` commands.
- Added a rule for how the agent uses Sentivel tools.
